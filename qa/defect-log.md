# MicroLend - Defect log and CAPA register

Single register of defects found from M2 onward, from any source, and of their corrective and
preventive actions (CAPA). Process and classification: [`inspections/README.md`](inspections/README.md).

**Rules**

- IDs `DEF-nnn` and `CAPA-nnn` are sequential and never reused.
- Rows are appended, not rewritten; status changes show in Git history.
- **Source** names the origin (`Inspection INS-nn`, `Static analysis (tool)`, `Test`, `CI`, `Review PR #n`, a repository or CI review, or an independent code review) and the finder; the separate "Found by" column was folded in on 21 Nov 2026 to fit the page.
- **Severity:** Major / Minor. **Type:** Logic / Data / Interface / Standards / Documentation.
- **Status:** Open -> Fixed -> Verified (closed); Deferred (justification and a CAPA); Rejected (not a defect; reason given).
- Closing needs the fix commit and the test or CI run that shows it.
- Static-analysis findings triaged *fixed* or *deferred* come from [`static-analysis-report.md`](static-analysis-report.md); false positives stay there.
